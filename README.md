# Pokemon GO API

Une API pour accéder aux données Pokémon GO.

## Structure

- `data/` - Données Pokémon (stats, mouvements, types, etc.)
- `locales/` - Traductions (français, anglais)
- `assets/` - Images et ressources
- `app.js` - Serveur principal
- `package.json` - Dépendances

## Installation

```bash
npm install
```

## Démarrage

```bash
npm start
```

Pour le développement avec auto-reload:

```bash
npm run dev
```

## Utilisation

Le serveur démarre sur le port 3000.
